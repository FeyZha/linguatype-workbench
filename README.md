# LinguaType

面向中文母语 IELTS 写作者的写作工作台。自己写作和修改，按需解决表达卡点，再从自己确认过的旧文中找到复用线索。

## 四步点击体验

1. **旧文复用**：打开大学服务题，点击“从旧文找线索”，查看旧观点、来源原句与改动方向。
2. **表达帮助**：切到公共服务草稿，点选中文；复杂意思先展示中文支架，英文按需翻开，不自动替换正文。
3. **审阅与保存**：检查待审阅稿中的两处建议，再亲自勾选确认并保存全文。草稿和确认快照分别保留。
4. **无关题目**：切到太空探索，体验没有合适线索的结果。也可以打开完全没有已确认旧文的场景。

## 数据与边界

这是不接入大模型的交互体验版。页面只使用内置合成作文和预置结果，无需账号或密钥，不发送模型/API请求。所有编辑与保存仅在当前浏览器，刷新可恢复；“重置样例”可重新开始。体验版有独立存储空间，不读取其他版本的个人工作区。

表达帮助只支持预置公共服务草稿的三处中文；全文审阅只支持预置待审阅稿和预置完成稿；复用线索只覆盖内置题目与可核对的原文。自由改写没有对应结果时会明确提示，不假装实时生成。不提供评分、自动改写或学习效果承诺。

公开版只保留前端和确定性校验，不包含模型服务、凭据、个人作文、私有研究语料或评测运行记录。静态部署通过浏览器策略禁止数据连接。

## 本地运行

需要 Node.js 22.13 或以上版本。在 prototype 目录执行 npm ci，然后 npm run dev:demo。检查使用 npm run test:demo、npm run typecheck 与 npm run build:demo。

预打包 ZIP 和 dist 已移除。源码仍可按上述命令本地运行和构建。公开源码尚未授予额外开源许可。
